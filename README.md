# C-entra21

💻 Algoritmos e Lógica de Programação com C#
Este repositório contém uma coleção de exercícios e projetos desenvolvidos durante minha jornada de aprendizado em lógica de programação utilizando a linguagem C#, realizados no programa Entra21.

O objetivo aqui foi consolidar conceitos fundamentais que servem de base para qualquer desenvolvedor de software, desde estruturas condicionais simples até manipulação de dados com CRUDs.

🚀 Tecnologias Utilizadas
Linguagem: C# (.NET Core / Framework)

IDE: Visual Studio

Paradigma: Programação Estruturada e Orientada a Objetos (básico)

📂 Estrutura do Repositório
Para facilitar a navegação, os exercícios estão divididos por categorias de complexidade:

1. Fundamentos e Estruturas de Controle
Condicionais: Verificadores de par ou ímpar, maioridade, sistema de notas e anos bissextos.

Laços de Repetição (While/For): Exercícios de contagem, adivinhação de números e cálculos matemáticos.

Recursividade: Implementações de Fibonacci e funções recursivas para entender o empilhamento de chamadas.

2. Estruturas de Dados
Vetores e Matrizes: Manipulação de arrays unidimensionais e bidimensionais para armazenamento e busca de informações.

3. Modularização (Funções)
Criação de métodos reutilizáveis para cálculos de IMC, verificação de números primos e processamento de dados.

4. Projetos Práticos (Sistemas CRUD)
Projetos mais complexos que envolvem o ciclo de vida completo dos dados (Create, Read, Update, Delete):

CRUD de Livros: Sistema simples para gestão de acervo.

CRUD de Produtos: Controle de estoque e preços.

Sistema de RH: Protótipo para gestão de funcionários.

🧠 Aprendizados Adquiridos
Durante o desenvolvimento destes códigos, foquei em:

Pensamento analítico para resolução de problemas.

Sintaxe e tipagem forte do C#.

Organização de código e nomenclatura de variáveis.

Entendimento de como o computador processa dados em memória (especialmente com matrizes e recursividade).
